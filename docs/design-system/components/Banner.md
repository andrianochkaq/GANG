# Banner

A rounded (`radius-lg`) block of 13–14 px text with an optional leading icon, used for warnings, tips and context lines inside a screen.

- `fc-banner--warning` (`status-soon-bg`, text `warning-text`, icon `status-soon-fg`): AI substitutions («Смак буде трохи інший»), unsure receipt lines («Розпізнано неточно. Натисніть, щоб уточнити назву.»). Start with what happened, then what it means.
- `fc-banner--tip` (`soft`): helpful context and summaries with an action link right («Ціль: схуднення · розраховано за вагою 65 кг — Змінити»).
- `fc-banner--info` (`surface`): neutral explanations on `bg` («Як працює реєстрація» with numbered steps).
- Banners never block; they never use red. Errors that block an action go next to the field (TextField).
- Persistent reminders (water behind pace, join request waiting) use a tip banner at the top of the screen with an action.
