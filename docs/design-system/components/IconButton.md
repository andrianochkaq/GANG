# IconButton

A round 44 px button (`size-control-sm`, `radius-pill`) holding one 20 px stroke icon; always has an `aria-label` in Ukrainian.

- Default: `surface` on `bg` — back («Назад»), settings, ⋯ more actions in a screen header.
- `--accent`: `accent` fill — send in AI Chef, «+» to add a recipe.
- `--danger`: transparent with `danger` icon — delete inside a product row.
- `--ghost`: transparent with `text-muted` icon — edit pencil in tables.
- `--onbg`: `bg` fill when the button sits on a white card (edit profile pencil).
- The back button is always the first element of a sub-screen header, left of the title.
- `aria-label` names the action and its object: «Видалити: Йогурт грецький».
