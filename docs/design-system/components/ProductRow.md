# ProductRow

One product in the fridge list (mobile): name and expiry badge on top; stepper, «Списати» and delete on the second line.

- Line 1: name 15 / 600, expiry Badge right.
- Line 2: Stepper (40 px), spacer, «Списати» link in `ink` (opens the write-off sheet), 40 px delete icon in `danger` (asks to confirm, then shows an Undo toast).
- Rows are separated by `divider` inside a white list card; sort Use First items first.
- Tapping the name opens the edit screen (shows who added it and when, and «Що приготувати з …?»).
- Desktop uses the DataTable instead.
