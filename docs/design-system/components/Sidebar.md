# Sidebar

Desktop navigation: a left column 220–272 px wide (`size-sidebar`) on `sidebar`, with the brand, the 4 main items, the current-fridge card and a Покупки button.

- Brand row: 36 px `soft` square with the house icon in `ink` + «FreeCook» Rubik 22.
- Items: 48 px rows, `radius-md`, 22 px icon + 15 px label; active = `soft` fill, `ink` 600, `aria-current="page"`. Same items and order as the BottomNav (Калорії only when on).
- Current fridge: white card with the mascot, «Наш холодильник» and «3 учасники · змінити»; opens the fridge list.
- Покупки: outlined 44 px button with the count of items still to buy.
- The main area to the right gets 24 px top and 40 px side padding.
- The design board for this was drawn before theming covered the whole app: use `soft`/`ink` from the user's theme here, not the board's fixed green.
