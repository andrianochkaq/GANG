# Switch

A 52 × 32 px track (`radius-pill`) with a 26 px white knob: on = `accent`, off = `toggle-off`.

- Only inside a list row, on the right. The row text says what turns on and its current setting in the meta line: «Нагадує, поки не досягнете норми · 2 л».
- The row title is a link to that feature's settings page; the switch toggles it in place. Changes save immediately — no Save button.
- `role="switch"`, `aria-checked`, `aria-label` = the row title.
- Turning a feature off hides it everywhere at once (e.g. the «Калорії» tab disappears from navigation).
